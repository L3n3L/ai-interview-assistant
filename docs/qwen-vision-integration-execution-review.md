## 文档状态

## 对接结论

本次接入不需要新的 Key。Qwen 实时语音和视觉识图均使用当前 Qwen DashScope Key；代码通过不同协议访问：

```text
实时语音：WebSocket / Qwen Realtime
截图识图：HTTPS / OpenAI 兼容 Chat Completions
```

图片以 Base64 `data:image/...` 放入多模态消息，模型返回文本流。首段正式文本创建回答，后续文本更新最后一条回答，因此识图结果自然进入现有三条分页。

## 执行前基线

- 当前 `send-image-content` 在 Qwen 模式直接返回“不支持截图”。
- 当前 DeepSeek、Gemini、Local AI 已有各自的图片实现。
- 当前回答 UI 已支持 `new-response`、`update-response` 和三条分页。
- 当前 Qwen 实时语音会话、音频采集和 VAD 不作为本次改动对象。

## 复盘关注点

1. 不能将视觉请求接入当前实时 WebSocket，否则会把图片时序和语音 VAD 绑在一起。
2. 不能把思考内容直接显示到回答卡片；只显示模型最终回答。
3. 不能在日志中记录图片 Base64、API Key 或完整敏感请求体。
4. 识图回答必须复用现有回答事件，否则会出现第二套分页状态。
5. 代码题质量优先，因此截图缩放不能继续固定为低清 1280 宽。
